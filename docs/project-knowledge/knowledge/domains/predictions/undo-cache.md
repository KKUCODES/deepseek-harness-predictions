# 接受、撤销与缓存恢复

状态：1.0.0 当前行为。维护角色：插件维护者。最近核验：2026-10-29。

接受和隐藏与丢弃是不同操作。Tab／单次右箭头写入草稿，非空草稿暂时隐藏灰字，但保留本轮 ready 缓存。Ctrl+Z 撤回至空草稿，或删除自行输入的全部文字后，复用相同建议，不请求模型。Esc 才持久记录丢弃；新回合使用新的 key。

宿主负责实际草稿和原生撤销，插件不截获 Ctrl+Z、不取得私有编辑器对象或改写撤销栈。在刚执行本地命令的会话中，首次填入的单步撤销仍有未通过边界，可选中删除。

## 首次进入与断线

自动和仅手动模式首次挂载均可只读恢复缓存。客户端尚未取得回合投影时，允许由公开宿主服务解析会话身份；“仅手动”不能等同于“不读缓存”。

输入取消请求后、浏览器刷新、宿主重启、重连或重新聚焦均核对已存结果，不自动重新生成。断线时隐藏可接受灰字并阻止新请求，读取失败不自动重试。

同源窗口只发送失效通知，其他窗口通过宿主核对；不从广播取得预测内容。缺少 BroadcastChannel 时，在聚焦及重新点击／Tab 进入输入框时降级核对，仅对已有缓存执行，不能抢先取消首次自动计时。跨设备和不同浏览器 profile 不承诺即时同步。
