# 接入与验收注意事项

状态：1.0.0 维护规则。维护角色：插件维护者。最近核验：2026-10-29。

## 设置与回合

宿主只暴露 volatile 配置字段；普通 Config 可使插件运行但 configForms 不可用。原生表单可能将网络失败返回为 false，需按 revision 区分保存失败与真正并发冲突。

仅手动模式首次挂载仍需只读 peek，包含客户端尚无回合身份的情况。回合由公开投影获取，不能扫描私有日志或伪造完成事件。

## 真实入口

安装器返回版本号不代表依赖完整或 Web 可启动。锁异常、模块缺失和插件兼容跳过分别排查，先定位使用的官方 CLI，再在隔离环境实际启动，不据 --version 便宣布修复，不修改宿主或全局缓存来掩盖插件问题。

Overlay 字段不能假设总是深度合并。修改持久化配置可能丢失 root 等必填值；验收保留默认存储配置，不为审计改宿主写入协议。

Host 重启健康检查不能只看端口或启动期 404；需确认 HTML 200 或鉴权 401／403。浏览器导航可用后才做恢复测试。

## 日志和调用计数

.jsonl.zstd 含多帧，须按解压返回的消耗字节遍历，并断言确实读取到会话记录。未读取任何文件不等于没有调用。宿主会将环境／技能／时间信息记为 user/message；判断实际发送须核对 source.kind:user，不能数所有 user/message。

接收 HTTP 200 或连接测试通过不代表预测成功，须核对 ready、有效正文、输入框灰字和实际用量。模拟宿主、单测和本地协议服务必须分别标明，不能当成厂商调用。

## 隔离与清理

每次随机目录保存独立 home、工作区和报告，不复制凭据或浏览器授权。Windows 持有 ChildProcess 句柄停止本次进程并核对端口，不按可能复用的 PID 递归清理。结束后检查宿主发布文件摘要，并清理本次厂商凭据。

Key 不能出现在错误正文、普通配置、日志、截图或 HTML 附件。失败后先清空密码输入框，不保存可能含 Key 的页面 HTML。取消不保证厂商没有计费，不自动再次收费。
