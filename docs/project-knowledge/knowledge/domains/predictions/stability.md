# 兼容性与稳定性

状态：1.0.0 当前边界。维护角色：插件维护者。最近核验：2026-10-29。

## 验证范围

正式包已在官方 Harness Web rc.3 / Edge 完成安装、认证、设置、参数传输、自动／手动预测、接受／撤销／缓存恢复和卸载，使用本地协议服务，宿主文件摘要前后相同；报告见[运行验收](../../../validation/README.md)。

运行实现的补充覆盖包括官方 Web rc.2 / Chrome、状态图标、深色与 1280／768／390 布局、减少动态效果、连接测试取消、失败、超时和迟到响应；相应记录见验收页。报告保留原包身份，不能将所有记录统称为正式包重新实测。

## 当前保证

- 草稿版本、输入状态、回合和请求身份在接受及采纳结果前核对，不覆盖后来输入。
- 附件、引用、排队、组合输入或运行状态下跳过预测；对不认识的 DOM／不可编辑状态保持原行为。
- 单一在途、持久尝试和只读缓存控制重复调用；断线恢复不会自动重试已发生的请求。
- 同源窗口失效通知只促使只读核对，不接受广播提供的正文。
- 停用／卸载会释放样式、监听和快捷键，恢复原 placeholder。
- 服务端响应有大小与格式边界，错误正文不回显 Key，不跟随重定向。

## 限制

刚执行本地命令后的首次填入，Ctrl+Z 单步撤销未通过；插件不改宿主撤销栈。真实系统输入法候选词窗口、Electron、跨设备实时同步、多个 Host 共用同一 home、长时间压力及工具／Agent 运行的完整流程未逐项验收。

浏览器合成组合输入事件不能当作真实输入法。不同浏览器 profile 或聚焦早于另一窗口提交时不承诺即时同步；无频道模式核对时可短暂隐藏灰字。取消已抵达厂商的请求仍可能收费。
