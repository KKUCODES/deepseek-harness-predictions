# 手动预测

状态：1.0.0 当前行为。维护角色：插件维护者。最近核验：2026-10-29。

手动操作为在空输入框快速按两次右方向键。判定窗口约 300 毫秒；单次按键在窗口结束后接受已有建议，第二次按键会取消延迟接受并执行一次手动动作。Tab 始终立即接受。

| 输入状态 | 两次 → 的行为 |
| --- | --- |
| 空白且无建议，真实预测已开启 | 生成一次预测 |
| 空白且已有建议 | 保留建议，不请求也不填入 |
| 存在任何草稿 | 保留光标操作，不生成 |
| 组合输入、会话运行、附件／引用／排队、总开关关闭 | 不生成 |

修饰键和长按重复不触发。按键后输入、焦点离开或回合变化会取消迟到填入。没有刷新建议的开关或生成路径。

## 已有聊天与请求身份

已有聊天可通过宿主公开投影解析完成回合；客户端 key 尚未到达时仍允许手动请求，由服务端核对实际身份。有 key 时必须与当前完成回合一致。空会话、无有效上下文或没有模型路由时跳过。

每次明确手势使用新 requestId；同一身份重发、在途重复操作、窗口并行均不能多发请求。手动至少间隔 1 秒；已有 ready 始终复用。失败／超时后可明确再试，不自动重试，不设每日次数上限。

实现比较：使用独立显式手势能区分接受与生成，并在已有聊天中补充缺失建议；直接用每次按键或焦点触发会增加误调用。当前选择不额外提供刷新已有建议。
