# 模型调用与持久去重

状态：1.0.0 当前实现。维护角色：插件维护者。最近核验：2026-10-29。

## 上下文与提示词

公开会话投影只允许正常完成且存在助手回复的回合产生 key；新回合、用户消息或中断会失效。使用 session.deriveMessages 和 requestHeader 获取会话文字与模型身份，不扫描私有日志。

默认最多 8 条用户／助手文字，每条截取末尾最多 500 个字符，整个 JSON 对话输入约 4000 字符；可调小。只选 source.kind 为 user 的用户输入及助手 text 块，排除系统、工具、附件、注入文件与思考；必须同时有用户文字且末条为助手。

完整提示词在[预测实现](../../../../../src/prediction.ts)的 SYSTEM_PROMPT。它要求以人的口吻和语言预测下一条自然单行消息，最多 120 字符，不编造事实、授权、凭据或目标；不能确定时返回 NO_PREDICTION 标记。对话 JSON 是数据，不是指令。

只显示符合筛选规则的完整短句：拒绝空值、标记、多行、控制字符、过长内容、代码／引号开头或“预测／建议”等标签。

## 调用路径

跟随会话或选择宿主模型时使用公开 llm.prepareCall，按模型公开能力选择最小思考档，最长输出默认 128、允许 32–256 Token。自定义连接走[Chat Completions](./custom-model.md)，采用其独立参数，不强制思考档。

分发前先向独立 attempts 存储写入回合、请求身份、模型及尝试状态，并记录用量。自动每轮至多一次；同一请求重发、并行窗口或宿主重启都不能自动绕过尝试记录。已有 ready 结果始终复用。明确手动操作允许补充失败／缺失结果，但不刷新已有建议。

同一宿主同时最多一个请求。超时、关闭、输入、断线、回合变化及取消都受状态检查，迟到结果不显示。先写存储失败则不请求模型；厂商已接收后取消仍可能收费，失败不自动重发。

只读 peek 仅核对已存 ready，可由公开投影解析已有会话的回合身份，不准备模型、不写次数；丢弃后的结果不恢复。

predict 不设置跨轮冷却；客户端取得完成回合后不添加固定等待。配置与设置表单不提供时间控制字段，已有 delayMs／cooldownSeconds 不读取、不保存或生效。

仅在尚未分发且其他请求占用时返回 skipped 和 retryAfterMs，客户端等待空闲后继续；失败、取消、空结果及只读核对不自动重试。等待任务绑定当前输入框与回合，离开或编辑即取消；普通聚焦不丢掉已排定的等待。
