# 预测消息状态

状态：1.0.0 当前实现。维护角色：插件维护者。最近核验：2026-10-29。

状态图标位于模型切换左侧。灰色空心圆为暂无预测，转圈为正在生成，绿色空心圆为本轮缓存可用。悬停标题固定为“预测消息状态”，第二行说明当前状态；失败与超时仍用灰圈，文字提示可双次右箭头重试。

宿主会话尚未加载完成，或其他预测／连接测试仍在途时，使用灰圈，悬停说明“等待自动生成”；资源就绪后自动分发并转圈。没有固定调用间隔，等待不是模型失败，不需要手动补触发。

图标只读，不接受焦点、不增加 Tab 停靠点，点击不会生成或刷新预测。关闭真实预测或使用效果测试时隐藏。接受、自行输入、撤销和清空期间保留可复用缓存，因此保持绿色；Esc、回合变化、取消和缓存丢弃会清理状态。

## 接入

使用公开 conversation.input.right 列表插槽，顺序在模型选择左侧；灰字使用 conversation.input.overlay。两者订阅同一共享请求状态，图标不持有请求生命周期，也不自行 acquire 或发模型请求。只读 peek 不显示生成中。

状态容器 28×28px，模型间距 8px；使用本地[灰圈](../../../../../src/client/assets/prediction-empty.svg)、[绿圈](../../../../../src/client/assets/prediction-ready.svg)、[加载图标](../../../../../src/client/assets/prediction-loading.svg)。悬停框 208×68px，按视口避让。加载旋转周期 1 秒；减少动态效果偏好下停止旋转，保留文字说明。

## 验证

npm run verify:status 使用官方 Web、真实安装包和本地协议服务验证自动／手动请求、失败超时、取消、缓存、响应式和卸载，不读取厂商 Key。现有[状态覆盖记录](../../../../../artifacts/undo/2026-10-28T17-48-52-360Z-ecafbb10/report.json)为独立组件行为证据；正式包入口另见[运行验收](../../../validation/README.md)，不混淆报告中的包身份。
