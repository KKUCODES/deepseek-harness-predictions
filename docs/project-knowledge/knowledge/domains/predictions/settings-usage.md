# 设置与只读用量

状态：1.0.0 当前实现。维护角色：插件维护者。最近核验：2026-10-29。

## 设置与保存

主页面保留启用、自动／仅手动、模型、今日 Token 和费用估算。更多设置按需调整上下文、输出、自填价格和效果测试；明细展示今日与累计用量。自动预测没有触发等待或跨轮调用间隔设置。

启用和效果测试即时保存，互斥开启；其他修改统一保存，测试句可单独保存。无有效修改时保存按钮置灰，改回原值重新置灰；保存中禁用相应操作。没有左侧“已保存”文案、勾选图标或成功横幅。

连接、请求参数及新凭据引用随自定义页原子保存，不先替换当前连接。保存携带编辑版本，网络失败与并发冲突分别提示，保留草稿；读取最新设置和放弃修改需确认。自定义模型名称直接显示，不加前缀。

## 统计与估算

插件没有每日次数、Token、金额上限或额度预占。调用按 UTC+8 日期记录，只统计本插件。失败／取消缺少完整用量时记为待核对，不当作免费，也不阻止下一次明确调用。

单价为人民币／百万 Token，由用户填写。两项均大于零时估算，零或单边缺失表示未定价；未定价不显示为零费用，不回算既有记录。没有官方价目表或自动匹配，服务商账单是最终依据。

账本使用独立 dsh_predictions_usage v1 的 daily 表，去重使用 dsh_predictions v1 的 attempts 表。兼容读取时忽略不再使用的多余字段，保留已记用量，不清空数据或扫描宿主日志。分发前先记一次待核对调用和尝试；有完整终态用量才结算。存储失败时不分发模型。

缓存、只读查询、接受和撤销不记新调用。模型目录与统计只在进入、明确更新或保存后读取，不轮询或触发生成。
