# 使用公开扩展接口，保留原输入框

状态：1.0.0 已采用。维护角色：插件维护者。最近核验：2026-10-29。

用户要求严格不修改宿主源码，通过独立插件提供输入框内灰字与键盘接受。

比较了已有插槽接入和重新提供整个输入框。后者需要自行维护附件、引用、菜单、输入法和队列，兼容与测试成本更高。采用公开扩展接口，接受 DOM 标记随宿主升级可能需适配的边界。

灰字由插件节点绘制；位置与字体只读，原 placeholder 只在灰字存在时用限定样式隐藏。草稿写入和快捷键走公开接口，不访问私有编辑器对象。遇到未知 DOM 或不可编辑状态时，不显示或接受灰字，保持原输入行为。

验证运行官方独立发布包，不构建或修改 Harness 本体。效果测试明确使用固定句，不能描述为模型预测；真实模型另行显式选择和核对。
